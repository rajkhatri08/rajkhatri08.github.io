Deployed · RAG & governance

Governed RAG: an answer you can audit

Source-Governed RAG — a retrieval system over regulatory documents where a source's approval status and review date can veto an otherwise perfect semantic match.

AUG 2026  ·  SOLO BUILD  ·  PYTHON  ·  FASTAPI  ·  CHROMADB  ·  POSTGRESQL  ·  NEXT.JS
384-DIMENSIONAL SENTENCE EMBEDDINGS SERVED VIA ONNX RUNTIME  ·  DEPLOYED ACROSS THREE SERVICES

THE FAILURE MODE

Semantic search will confidently answer from an expired internal policy if it happens to be the closest match. I reproduced exactly that: a lapsed document outranking current regulation on similarity, returning a deadline that would place an organisation in breach.

So approval status and review date are enforced as a veto, not a weighted score — a strong semantic match cannot outrank a failed trust check. Results tier gold, silver, bronze; the best-scoring match in the whole evaluation set is still bronze, because its source was never approved.

  1. Retrieval quality

    Accuracy went from 78% to 95% on the labelled set by replacing fixed-size character chunking with document-structure chunking. I found the cause by reading the retrieved text rather than tuning prompts: character windows were truncating enumerated legal clauses before the subsection containing the answer. Regex lookahead splitting now keeps whole provisions with their headings intact.

  2. Evaluation

    A 23-question hand-labelled set — deliberately small and adversarial rather than broad, spanning answerable, out-of-corpus and conflicted cases with plausible negatives built to provoke false confidence. It's an edge-case audit, not a scale benchmark, and the accuracy figures should be read that way; the next step is running it against a larger uncurated corpus.

    Within that set I swept 70 similarity thresholds, measured a 73.9% accuracy ceiling for distance-based confidence, and removed the feature rather than ship an unreliable signal. Grounding was verified by querying a fact the model knows but the corpus doesn't, and confirming refusal.

  3. Audit trail

    Every request writes timestamp, tier, reasoning, sources, distances and warnings to PostgreSQL, so any decision is reconstructable months later. Document text lives on disk while all governance state lives in the database — one source of truth for trust decisions. Six-endpoint FastAPI service with schema validation and generated OpenAPI docs.

  4. Running it in production

    First deploy failed: 2 GB of GPU libraries on a 512 MB instance. Swapping to an equivalent ONNX runtime cut the footprint by roughly 96%, verified behaviour-identical before shipping. Evaluation runtime went from 4.5 minutes to 2 seconds through result caching keyed to invalidate on configuration change. Audit logging moved off the filesystem to PostgreSQL after ephemeral instances erased runtime writes on restart, and infrastructure failures are separated from model refusals so a provider outage can't corrupt an accuracy measurement.

Investigation · Applied statistics

A defect nobody had cracked

Raw data to business decision, end to end — messy inputs, an explicit method, a falsifiable hypothesis, physical validation, a shipped artifact, and a stakeholder review.

TATA MOTORS  ·  DATA ANALYTICS INTERN  ·  JUL–AUG 2026  ·  PANTNAGAR, UTTARAKHAND  ·  BODY-IN-WHITE QUALITY

01 — PROBLEM

A Body-in-White dimensional defect in the weld shop, unresolved long enough that a clean data-driven answer wasn't expected anymore. No labelled dataset, no schema — inspection records collected for compliance, not analysis.

02 — METHOD

Linear regression with R² confidence scoring across ~300 inspection points. The hypothesis was falsifiable by design: if on-line equipment wear were the cause, the pattern would drift with time on the line. It didn't — flat fit, no correlation. But a subgroup was climbing steadily toward the upper limit.

03 — VALIDATION

The subgroup traced to one supplier batch, so I measured the parts physically on the line. The gauge matched the prediction — a supplier-side dimensional issue, not our equipment. A model that agrees with itself proves nothing; this one had to agree with a gauge.

04 — DELIVERY

A containment procedure needing no production stoppage or vendor dependency, a dashboard tracking 10 quality metrics, and a 20+ section report benchmarked against DFMEA and Six Sigma — presented to the BIW Shop Head, where the method had to hold up, not just the result.
